# Airplane Tracker

Консольное приложение на Python для поиска и просмотра информации о самолётах, находящихся в воздушном пространстве выбранной страны

Проект использует открытые API для получения географических координат и информации о воздушных судах. Полученные данные можно сохранять, просматривать и фильтровать

## Возможности

- Поиск самолётов над выбранной страной
- Получение информации о самолётах через OpenSky Network API
- Определение географических границ страны через Nominatim API
- Просмотр информации о самолёте:
  - ICAO24;
  - позывной (Callsign);
  - страна происхождения;
  - высота полёта;
  - скорость;
  - вертикальная скорость
- Вывод топ N самолётов по высоте полёта
- Фильтрация самолётов по стране происхождения
- Сохранение полученных данных в JSON
- Добавление, получение и удаление записей из хранилища

## Технологии

- **Python 3.14.5**
- **Requests** — выполнение HTTP-запросов
- **OpenSky Network API** — получение информации о самолётах
- **Nominatim API** — получение географических координат стран
- **JSON** — хранение данных
- **Pytest** — тестирование
- **Pytest-cov** — анализ покрытия кода тестами

## Использование

После запуска приложение предложит ввести название страны

Например:

```text
Введите название страны для поиска самолётов или 0 для выхода: Germany
```

После получения данных появится меню:

```text
Выберите действие:
1. Показать топ N самолётов по высоте
2. Найти самолёты по стране происхождения
3. Выполнить новый поиск по другой стране
0. Выйти из программы
```

### Пример возможностей

**Топ N самолётов**

Пользователь указывает количество самолётов, после чего приложение выводит список воздушных судов с наибольшей высотой полёта

**Фильтрация по стране происхождения**

Позволяет найти самолёты определённой страны среди уже полученных результатов поиска

**Сохранение данных**

Полученные данные сохраняются в файл:

```text
data/aeroplanes.json
```

Записи идентифицируются по ICAO24. Если самолёт уже существует в хранилище, его информация обновляется

## Тестирование

Для запуска всех тестов:

```cmd
pytest -v
```

Для проверки покрытия кода:

```cmd
pytest --cov=src --cov-report=term-missing
```

Для создания HTML-отчёта:

```cmd
pytest --cov=src --cov-report=html
```

После выполнения команды HTML-отчёт будет находиться в директории `htmlcov/`

Тесты проверяют:
- создание объектов и валидацию данных;
- сравнение самолётов;
- преобразование ответов API в объекты;
- обработку HTTP-ответов;
- работу JSON-хранилища;
- добавление, получение и удаление данных;
- сортировку и фильтрацию;
- работу консольного интерфейса.

## Архитектура

Проект построен с использованием объектно-ориентированного программирования

Основные компоненты:

- `BaseAPI` — абстрактный класс для взаимодействия с API
- `NominatimAPI` — получение географических данных
- `OpenSkyAPI` — получение информации о самолётах
- `AeroplanesAPI` — объединение работы двух API
- `Aeroplane` — модель самолёта с валидацией и методами сравнения
- `BaseSaver` — абстрактный интерфейс хранилища
- `JSONSaver` — реализация сохранения данных в JSON
- `run_user_interface` — управление взаимодействием с пользователем
